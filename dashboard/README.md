# 🎧 boAt UK Market Entry Strategy & Financial Engine
### Corporate Strategy, Financial Feasibility & Unit Economics Dashboard (2027–2029)
**Target Roles:** Corporate Strategy Manager/Analyst • Management Consulting Associate • Business / Data Analyst  
**Subject:** Imagine Marketing Limited (`boAt`) – International Expansion into the United Kingdom

---

## 📌 Executive Overview
This interactive web dashboard models the strategic, regulatory, and financial feasibility of **boAt (Imagine Marketing Limited)** executing a phased, 3-year market entry into the **United Kingdom Personal Audio Market ($576.9M TAM)**.

Rather than a theoretical case study, this application is grounded in:
1. **4 Years of Audited Standalone & Consolidated Financials (FY23–FY26)** and the **Draft Red Herring Prospectus (DRHP)** filed with SEBI.
2. **Official UK Trade & Regulatory Statues**:
   - **HMRC Integrated Online Tariff** (Commodity Code `8518 30 00` for headphones/earphones & 20% VAT).
   - **UKCA Marking Directives** (Radio Equipment Regs 2017, UK Authorized Representative, DoC).
   - **WEEE Regulations 2013/2025** (DEFRA producer compliance quotas, Producer Compliance Scheme enrollment, BS EN 50419 battery directives).
3. **Multi-Channel Commercial Architecture**:
   - **Phase 1 (Months 1–12)**: Digital Exclusive via **Amazon.co.uk (FBA)** + **boAt D2C (Shopify)** supported by an outsourced **Midlands 3PL** (Birmingham).
   - **Phase 2 (Months 13–24)**: Selective Omnichannel Wholesale via **Argos, Currys**, and high-volume **Supermarkets (Tesco Extra, Sainsbury's, Asda)**.
   - **Phase 3 (Months 25–36)**: Scaled Market Maturity achieving **£25.5M ARR (850,000 units)** at **10.6% Net PAT Margin**.

---

## 🚀 Key Financial Highlights & Milestones
- **Disruptive Price Point:** Positioned at **£24.99 – £39.99 MSRP**, capturing the uncontested *"Lifestyle-Value"* white space against Apple/Sony (£150+) and generic unbranded hardware.
- **Operating Break-Even:** Exact inflection achieved at **Month 22–24** as physical retail scale absorbs customer acquisition burn.
- **Landed Unit Margin:** Factory FOB assembly through boAt's domestic **Califonix JV (with Dixon Technologies)** ensures an industry-leading **65.7% gross product margin** and **21.9% net contribution margin** per unit sold.
- **Domestic Capital Security:** Backed by boAt's FY26 balance sheet turnaround (**₹921.5 Mn Standalone PAT**, **zero bank debt**, and **₹350+ Cr in liquid reserves**). Peak UK seed capital at-risk is **£415k (<1.2% of domestic cash)**.

## 🛠️ Local Development & Quick Start

### 1. Prerequisites
Ensure **Node.js (v18+)** is installed.

### 2. Installation
```bash
# Navigate to the dashboard directory
cd boat-uk-strategy-dashboard

# Install dependencies
npm install
```

### 3. Run Locally
```bash
# Start Vite development server
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for Production
```bash
npm run build
npm run preview
```
